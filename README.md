## 1. Project Overview

This repository contains the **front-end Vue.js application** for an After School Class App.

The app allows students and parents to:

- View a list of after-school lessons/activities (each with subject, location, price, spaces, rating, and an image/icon).
- Sort lessons by different attributes (subject, location, price, spaces).
- Add lessons to a shopping cart, respecting available spaces.
- View and manage the cart (remove lessons, restore spaces).
- Complete a checkout form with validation on **Name (letters only)** and **Phone (numbers only)**.
- Submit an order, which is sent to the **Express.js / MongoDB back-end** via REST API.
- Update lesson spaces after a successful order.
